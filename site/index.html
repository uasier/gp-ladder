连涨天梯是什么软件？

连涨天梯是开源的 A 股行情浏览工作台，可在 macOS、Windows 和 Android 上使用。它从同花顺抓取连续上涨榜，从东方财富读取涨停池、昨日涨停和当日行情，在本地筛选、精选并导出，不构成投资建议。

连涨榜、涨停天梯和昨日涨停分别看什么？

连涨榜来自同花顺连续上涨排名；涨停天梯来自东方财富涨停池，按连板高度分档；昨日涨停看昨天涨停、今日竞价后仍红盘且涨幅在 2% 到 8% 的标的。

数据从哪里来？需要一直联网吗？

连涨榜来自同花顺，涨停与行情来自东方财富。打开软件只读本地快照；点击「刷新实时数据」才会联网。页面结构若变更，解析可能失败。

如何下载连涨天梯？

在官网下载区选择版本与系统，下载 macOS DMG、Windows 安装包或 Android APK。安装包来自 GitHub Releases，应用内「设置 → 关于」也可检查更新。

Mac 可在「关于本机」查看芯片类型：Apple M 系列选 Apple Silicon，Intel 处理器选 Intel。手机浏览器可直接下载 Android APK。

macOS 提示无法打开或「已损坏」怎么办？

当前安装包尚未经过 Apple 公证。先将应用拖入「应用程序」，确认从本官网或项目 GitHub Releases 下载，再到「系统设置 → 隐私与安全性」尝试「仍要打开」。

若仍提示损坏，可在终端执行以下命令：

xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app

Windows 如遇 SmartScreen，请先确认安装包来源；Android 安装时可能需要允许浏览器安装应用。

DeepSeek 分析需要额外付费吗？

软件免费。使用短线分析需在设置中填写自己的 DeepSeek API Key，模型调用费用由 DeepSeek 按其规则收取。未配置时仍可使用榜单、筛选和导出。

连涨天梯会给出买入卖出建议吗？

不会。榜单、筛选、精选标记、评分和模型生成的文字只供学习交流，不能替代独立研究或持牌投资顾问意见。
