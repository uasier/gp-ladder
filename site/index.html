Boards

三个榜单

一个窗口切换连涨、涨停和昨涨，不再在同花顺和东方财富之间来回切。

连涨天梯

读取同花顺连续上涨榜，按连涨天数分档，叠加现价、涨跌幅、今开高低、换手、成交额、市盈率和散户资金。

涨停天梯

读取东方财富涨停池，按连板高度分档，观察涨停梯队而不是只看一张混排列表。

昨日涨停

看昨天涨停、今日竞价后仍红盘且涨幅 2%–8% 的标的，用来跟竞价强度和回封节奏。

Workflow

怎么用

1

打开即看快照

启动后读取本机上次榜单，不自动联网。适合先看盘、再决定要不要刷新。

2

刷新实时数据

需要最新榜时再点刷新。连涨来自同花顺，涨停和行情来自东方财富。

3

筛选、精选、导出

按行业、天数、涨幅、换手和散户指数过滤，导出 HTML / CSV / JSON。

macOS 提示「文件已损坏」怎么办？

安装包没有 Apple 公证。macOS 15 及以后会把这种情况显示成损坏。把「连涨天梯」拖进「应用程序」后，在终端执行： 

xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app

Windows 如遇 SmartScreen 选择「仍要运行」。Android 需允许安装未知来源。

FAQ

常见问题

连涨天梯是什么软件？

连涨天梯是开源的 A 股行情浏览工作台，可在 macOS、Windows 和 Android 上使用。它从同花顺抓取连续上涨榜，从东方财富读取涨停池、昨日涨停和当日行情，在本地筛选、精选并导出，不构成投资建议。

连涨榜、涨停天梯和昨日涨停分别看什么？

连涨榜来自同花顺连续上涨排名；涨停天梯来自东方财富涨停池，按连板高度分档；昨日涨停看昨天涨停、今日竞价后仍红盘且涨幅在 2% 到 8% 的标的。

数据从哪里来？需要一直联网吗？

连涨榜来自同花顺，涨停与行情来自东方财富。打开软件只读本地快照；点击「刷新实时数据」才会联网。页面结构若变更，解析可能失败。

如何下载连涨天梯？

到 GitHub Releases 下载 macOS dmg、Windows 安装包或 Android APK。应用内设置 → 关于也可检查更新并下载当前系统对应的安装包。

连涨天梯会给出买入卖出建议吗？

不会。榜单、筛选、精选标记、评分和模型生成的文字只供学习交流，不能替代独立研究或持牌投资顾问意见。
