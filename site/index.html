连涨天梯

开源的 A 股连涨榜、涨停天梯与昨日涨停工作台。从同花顺抓取连续上涨榜，叠加东方财富当日行情，在 macOS、Windows 和 Android 窗口里筛选、精选并导出。

三个榜单

连涨天梯

读取同花顺连续上涨榜，按连涨天数分档，叠加现价、涨跌幅、今开高低、换手、成交额、市盈率和散户资金。

涨停天梯

读取东方财富涨停池，按连板高度分档，观察涨停梯队而不是只看一张混排列表。

昨日涨停

看昨天涨停、今日竞价后仍红盘且涨幅 2%–8% 的标的，用来跟竞价强度和回封节奏。

能做什么

本地筛选

按行业、天数/连板、涨幅、换手、散户指数和精选标记过滤，卡片或列表两种视图。

短线分析

右键或长按个股，按 1–5 个交易日视角调用 DeepSeek 看盘，并给出 0–100 短线评分。

导出与更新

导出 HTML / CSV / JSON。设置里检查 GitHub Release，下载当前系统对应的安装包。

界面

下载

安装包在 GitHub Releases ：macOS 用 gp-ladder_*_aarch64.dmg 或 gp-ladder_*_x64.dmg，Windows 用 gp-ladder_*_x64-setup.exe，Android 用 gp-ladder_*_aarch64.apk。

macOS 若提示「文件已损坏」，不是下载坏了，按 仓库说明 在终端给应用补临时签名。Windows 如遇 SmartScreen 选择「仍要运行」。Android 需允许安装未知来源。

常见问题

连涨天梯是什么软件？

连涨天梯是开源的 A 股行情浏览工作台，可在 macOS、Windows 和 Android 上使用。它从同花顺抓取连续上涨榜，从东方财富读取涨停池、昨日涨停和当日行情，在本地筛选、精选并导出，不构成投资建议。

连涨榜、涨停天梯和昨日涨停分别看什么？

连涨榜来自同花顺连续上涨排名；涨停天梯来自东方财富涨停池，按连板高度分档；昨日涨停看昨天涨停、今日竞价后仍红盘且涨幅在 2% 到 8% 的标的。

数据从哪里来？需要一直联网吗？

连涨榜来自同花顺，涨停与行情来自东方财富。打开软件只读本地快照；点击「刷新实时数据」才会联网。页面结构若变更，解析可能失败。

如何下载连涨天梯？

到 GitHub Releases 下载 macOS dmg、Windows 安装包或 Android APK。应用内设置 → 关于也可检查更新并下载当前系统对应的安装包。

连涨天梯会给出买入卖出建议吗？

不会。榜单、筛选、精选标记、评分和模型生成的文字只供学习交流，不能替代独立研究或持牌投资顾问意见。

本项目仅供学习交流，不构成任何投资建议，也不是证券公司或投资顾问产品。行情可能延迟、不准或中断。
