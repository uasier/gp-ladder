# 连涨天梯 v0.2.12

## 自选列表与 Excel 导出

- 自选池保留原来的卡片，也可以切换到列表。列表里仍可打开详情、编辑和移除；移除沿用原来的确认，点击整行不会删除。
- 可以按代码、名称、行业或原因搜索，并按市场、行业筛选。现价、今日涨跌幅、自选以来收益、自选价格、连涨天数、换手率和量比可以填写区间，也可以按这些数值排序。没有行情时显示 `--`，不会把缺失当成 0；0 仍按 0 参与比较和排序。搜索 `000001` 会保留前导零。
- 可以显示或隐藏列表字段、调整顺序，并恢复默认。股票代码和简称始终保留。视图和字段配置保存在本机，不覆盖自选记录本身。筛选条件不单独保存。
- 可以导出真正的 `.xlsx`，选择全部自选或当前筛选结果。导出行序与当前排序一致，列与当前展示字段一致。表头为中文并标明单位；日期按日期写入，价格和收益按数字写入。股票代码按文本保存以保留前导零，缺失留空，0 会保留。以 `=`、`+`、`-`、`@` 开头的备注按文本写入，不会变成公式，也不含宏或外链。
- 网页在浏览器里下载。macOS 和 Windows 使用原来的保存对话框，取消保存不会提示成功。Android 写入应用自己的导出目录后尝试用系统打开，不能选择普通桌面路径。文件在本机生成，不会上传自选数据。
- 这次用标注的示例数据检查了网页宽屏和约 390px 窄屏。没有安卓真机验证，也没有 GTK 桌面原生界面验证。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.12_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.12_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.12_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.12_aarch64.apk`

官网下载：https://gp.uasier.com/

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。从 v0.2.7 起，Android 安装包使用固定证书，可以直接覆盖安装；从 v0.2.6 及更早版本升级时仍需要卸载一次。卸载会清除本机数据，请先自行保留需要的配置。仍需允许安装未知来源。
