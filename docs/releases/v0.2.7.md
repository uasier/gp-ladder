# 连涨天梯 v0.2.7

## Android 覆盖安装

- 发布的 APK 改为固定证书签名。从本版本起，后续版本可以直接覆盖安装，应用设置和自选记录会保留。
- v0.2.6 及更早版本每次构建都会生成新的测试证书，系统会提示签名冲突。从这些版本升级到 v0.2.7 时，仍需要卸载一次。卸载会清除本机数据，请先自行保留需要的配置。
- 仍需允许安装未知来源。证书指纹见仓库中的 `src-tauri/gen/android/release-cert.sha256`。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.7_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.7_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.7_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.7_aarch64.apk`

官网下载：https://gp.uasier.com/

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。

完整变更：https://github.com/uasier/gp-ladder/compare/v0.2.6...v0.2.7
