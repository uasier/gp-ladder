# 连涨天梯 v0.2.5

## 本次更新

- 导出入口统一收进「工具箱 → 数据与系统 → 导出当前榜单」，支持 HTML、CSV、JSON，移除顶部重复的导出下拉框。
- 修复保存 DeepSeek API Key 后仍显示「请先在设置中填写 DeepSeek API Key」的问题；AI 快速选股和个股分析两个入口均立即更新，无需刷新或重启。
- 空白 Key 或保存失败时仍保留填写提醒；行情失败等其他通知正常保留。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.5_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.5_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.5_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.5_aarch64.apk`

官网下载：https://gp.uasier.com/

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。Android 需允许安装未知来源；当前 APK 使用构建时生成的测试签名，覆盖安装旧版可能提示签名冲突。遇到该情况需先卸载旧版；卸载会清除应用设置和本地缓存，请提前保留需要的配置。

完整变更：https://github.com/uasier/gp-ladder/compare/v0.2.4...v0.2.5
