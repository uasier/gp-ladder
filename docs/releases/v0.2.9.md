# 连涨天梯 v0.2.9

## 股东人数

- 打开个股详情时，可查看该股最近一次披露的股东人数，单位为户。
- 同时显示统计截止日和公告日期。没有公告日期时显示「未提供」，避免把披露数据看成实时人数。
- 最新一条按统计截止日选择；同一截止日再取较新的公告日期。日期缺失时不会用当前时间代替。
- 沪市、深市、北交所代码会和市场后缀核对。没有披露时显示「暂无披露」；数据源失败时显示「暂不可用」，并可重试。失败结果不会被当成空数据缓存。
- 只在打开某只股票时请求。同一代码在 6 小时内复用结果，并发查看会合并为一次请求。
- 本次发布说明不包含原生实机安装验证。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.9_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.9_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.9_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.9_aarch64.apk`

官网下载：https://gp.uasier.com/

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。从 v0.2.7 起，Android 安装包使用固定证书，可以直接覆盖安装；从 v0.2.6 及更早版本升级时仍需要卸载一次。卸载会清除本机数据，请先自行保留需要的配置。仍需允许安装未知来源。

完整变更：https://github.com/uasier/gp-ladder/compare/v0.2.8...v0.2.9
