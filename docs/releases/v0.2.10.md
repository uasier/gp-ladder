# 连涨天梯 v0.2.10

## 榜单改由本机行情库计算

- 连涨天梯不再翻页抓取同花顺榜单，改为按本机行情库的收盘价计算连续上涨天数和累计涨跌幅。
- 涨停天梯同样改为按涨停价判定连板，连板身位、累计涨跌幅和累计换手都由本机行情库计算。昨日涨停仍取东方财富涨停池。
- 首次刷新会补齐最近交易日：先补最近 2 个交易日，其余按日历回看约 45 天补齐，默认最多约 30 个交易日。第一次刷新会比以往慢一些，之后只补缺失的日期。
- 非交易日会被记下来，不再反复请求；数据源偶发失败时保留已有行情，并在日志里说明哪一天没更新。
- 设置里的「最多抓取页数」改为「每次最多补齐交易日」，0 表示自动补齐最近约 30 个交易日。

## 自选池行情更完整

- 自选池列表新增连涨、连板、换手、量比四列，卡片增加成交额；行业优先用实时行情补齐。
- 个股详情可从实时行情补出今开、今高、今低、换手、量比、成交额、市盈率和散户资金；导出沿用同一套字段。
- 涨停个股的详情会显示「涨停特征统计」，例如「8 天 2 板」。

## 文案与交互

- 刷新按钮统一为「刷新行情」，不再区分「刷新现价」。
- 连涨天梯的分档说明由「连续收阳」改为「连续上涨」，与按收盘价计算的规则一致。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.10_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.10_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.10_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.10_aarch64.apk`

官网下载：https://gp.uasier.com/

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。从 v0.2.7 起，Android 安装包使用固定证书，可以直接覆盖安装；从 v0.2.6 及更早版本升级时仍需要卸载一次。卸载会清除本机数据，请先自行保留需要的配置。仍需允许安装未知来源。
