# 连涨天梯 v0.2.11

## 个股股性指标

- 个股详情在股东人数下方新增「股性指标」。打开一只股票时才读取它自己的日 K，不扫描全市场，也不改现有行情刷新。
- 分数综合最近最多 60 个已收盘交易日的四个维度：涨停 30、连涨 20、波动 30、成交活跃 20。上海时间 15:05 前的当日日 K 不计入。样本少于 40 天，或任一维度有效观察不足 30 个，不计算总分，也不用 0 补齐。
- 这是本应用自己的规则分，不是交易所、券商的官方股性指标，也没有用历史收益做过回测。分数高只表示这段时间更常收到涨停价、连涨更长、波动更大、换手更高，不表示这只股票更好，也不预测它还会上涨。
- 涨停按板块普通涨停价判断：沪深主板 10%，创业板 2020-08-24 起 20%、此前 10%，科创板 20%。代码以 4、8、92 开头的按北交所 30% 估算，不能区分老三板或已切换代码的历史规则。没有历史 ST 名单，主板以及创业板改革前收到 5% 涨停价附近记为无法判断，不用当前名称回推全部历史。上市初期无涨跌幅只在返回的两套日 K 都少于 90 根时，把开头 1 或 5 个交易日标成无法判断。
- 连涨和波动使用前复权收盘价，避免除权、拆股造成虚假大波动。成交活跃使用平均换手率，不用成交额。数据源失败时不给出分数。
- 本次发布没有安卓真机验证，也没有 GTK 桌面原生界面验证。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.11_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.11_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.11_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.11_aarch64.apk`

官网下载：https://gp.uasier.com/

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。从 v0.2.7 起，Android 安装包使用固定证书，可以直接覆盖安装；从 v0.2.6 及更早版本升级时仍需要卸载一次。卸载会清除本机数据，请先自行保留需要的配置。仍需允许安装未知来源。
