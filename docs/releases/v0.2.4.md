# 连涨天梯 v0.2.4

## AI 快速选股

- 新增「工具箱 → AI 快速选股」，将点击时当前筛选列表交给 DeepSeek 比较，推荐最多 4 只短线观察候选。
- 展示相对评分、入选理由、主要风险和观察条件；三个榜单均可使用，不足 4 只时按实际数量展示。
- 候选较多时分组初选后汇总复评。分析期间可收起窗口，稍后查看进度或上次结果。
- 新增「设置 → DeepSeek 智能模型 → AI 选股」提示词配置，支持变量插入和恢复默认，独立于个股分析与评分提示词。
- 校验模型返回的股票范围、重复项与结果完整性；异常时可重试。

## 行情与工作台

- 新增量比行情、卡片及详情展示、最小/最大量比筛选，并保留在 CSV、JSON 和 HTML 导出中。旧快照点击「刷新实时数据」后可补齐量比。
- 刷新时间改为「刚刚」「几分钟前」等相对时间，并自动更新。
- 完善悬浮工具箱、高级筛选弹窗、模块显示开关和移动端布局，精简重复说明。
- 新增同花顺个股跳转入口，完善 DeepSeek 连接配置与连接测试。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.4_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.4_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.4_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.4_aarch64.apk`

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。Android 需允许安装未知来源；当前 APK 使用构建时生成的测试签名，覆盖安装旧版可能提示签名冲突。遇到该情况需先卸载旧版；卸载会清除应用设置和本地缓存，请提前保留需要的配置。

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

AI 选股使用已配置的 DeepSeek 接口、模型和 API Key，仅依据提供的行情快照进行相对比较；候选较多时会产生多次模型调用。相对评分不代表上涨概率。
