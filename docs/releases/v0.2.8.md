# 连涨天梯 v0.2.8

## AI 选股加入自选

- AI 快速选股完成后，每只结果旁可以点击「加入自选」。
- 股票代码、名称、行业和价格来自本次候选快照，并按沪市、深市、北交所校验后再写入现有自选池。
- 已在自选池中的股票显示「已加入」。再次点击会编辑原来的记录，不会重复添加。
- 无法唯一对应候选股票时不会加入。价格、成交额等数字不会被当成股票代码。
- 加入后可在原来的自选池查看，仍按本机自选记录保存。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.8_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.8_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.8_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.8_aarch64.apk`

官网下载：https://gp.uasier.com/

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。从 v0.2.7 起，Android 安装包使用固定证书，可以直接覆盖安装；从 v0.2.6 及更早版本升级时仍需要卸载一次。卸载会清除本机数据，请先自行保留需要的配置。仍需允许安装未知来源。

完整变更：https://github.com/uasier/gp-ladder/compare/v0.2.7...v0.2.8
