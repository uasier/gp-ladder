# 连涨天梯 v0.2.6

## 自选池

- 新增独立页面「自选池」。可从榜单星标、右键菜单、个股详情加入，也可在页面里手动填写代码。
- 记录自选日期、自选价格和自选原因。同一只股票不会重复加入，之后可以编辑日期、价格和原因。
- 支持搜索，以及按自选日期、自选价格、自选以来涨跌、今日涨跌、名称和原因排序。
- 移除前需要再次确认。刷新现价只更新当前行情，不会改写当时记下的自选价格。
- 记录保存在本机应用目录的 `watchlist.json`，不会上传。卸载应用或清除数据会一并删除。

## 安装包

- macOS Apple Silicon：`gp-ladder_0.2.6_aarch64.dmg`
- macOS Intel：`gp-ladder_0.2.6_x64.dmg`
- Windows 64 位：`gp-ladder_0.2.6_x64-setup.exe`
- Android ARM64：`gp-ladder_0.2.6_aarch64.apk`

官网下载：https://gp.uasier.com/

应用内「设置 → 关于」可检查更新并下载当前系统的安装包。

macOS 安装包已做临时签名，尚未 Apple 公证。如系统提示「文件已损坏」，将 App 拖到「应用程序」后，在终端执行：

```bash
xattr -cr /Applications/连涨天梯.app
codesign --force --deep --sign - /Applications/连涨天梯.app
open /Applications/连涨天梯.app
```

Windows 如遇 SmartScreen，选择「仍要运行」。Android 需允许安装未知来源；当前 APK 使用构建时生成的测试签名，覆盖安装旧版可能提示签名冲突。遇到该情况需先卸载旧版；卸载会清除应用设置、自选记录和本地缓存，请提前保留需要的配置。

完整变更：https://github.com/uasier/gp-ladder/compare/v0.2.5...v0.2.6
